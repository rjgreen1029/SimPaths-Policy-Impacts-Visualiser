Citing the SimPaths model

This dashboard visualises outputs from SimPaths, a dynamic microsimulation model developed by the Centre for Microsimulation and Policy Analysis (CeMPA) at the University of Essex, and extended by researchers at the University of Glasgow as part of the Policy Modelling for Health research group. If your work involves using the SimPaths model and the visualiser, cite SimPaths directly along with the visualiser and consult its own documentation for the current recommended citation.

SimPaths documentation ↗ GitHub repository ↗ SimPaths License ↗

Citing the underlying survey data

The population and behavioural relationships behind SimPaths are built from Understanding Society: the UK Household Longitudinal Study. If you use results derived from this data, please cite the dataset itself in addition to the model.

Current citation (verify against the live page before publishing)

University of Essex, Institute for Social and Economic Research (2026). Understanding Society: Waves 1-15, 2009-2024 and Harmonised BHPS: Waves 1-18, 1991-2009. [data collection]. 21st Edition. UK Data Service. SN: 6614, DOI: http://doi.org/10.5255/UKDA-SN-6614-22

This citation updates with every data release

Understanding Society issues a new edition (with an updated DOI) each time a wave is added, so the exact wording above will go stale. Always confirm the current version at the official citation page before publishing.
